# LZ shape -> native shape

One row per settled native idiom: what the faithful port (EmiBSD.LZ) writes to mirror the C,
what this system writes instead, and why. A row is added in the commit that first uses the
idiom, not before. `docs/C_TO_RUST.md` (C -> LZ shape) is frozen and stays the key to reading
LZ code; this table starts where it ends.

Columns: LZ shape | native shape | why.

| LZ shape (mirrors the C) | Native shape | Why |
|---|---|---|
| A C status code returned as `i32` (zlib's `Z_OK`, `Z_STREAM_END`, `Z_NEED_DICT`, `Z_BUF_ERROR`, ...) and compared by every caller; a mode passed as an `i32` constant (`Z_FINISH`) | `Result<Status, Error>`: the `Ok` carries the non-error statuses (`Result<(), Error>` when success is only `Z_OK`), the `Err` a typed error enum; each type has `code()` for the C value, and the `Z_*` constants stay as those values; the mode is an enum (`Flush`) with its own `code()` (`sys/lib/libz/zlib.rs`) | `?` and `match` replace the comparisons; an error cannot be mistaken for progress, and an out-of-range mode cannot be built. Callers that keep a status integer of their own (libsa's `cread`) take `.code()` |
| A hash or MAC context struct and C-named free functions over it: `X_Init(&mut ctx)`, `X_Update(&mut ctx, data)`, `X_Final(&mut out, &mut ctx)` (`MD5Init`, `SHA256Final`, `SipHash24_End`, `blake2s_final`) | A type with methods: `XCtx::new()` (or `new(key)` for a keyed one) is `Init`, `update(&mut self, &[u8])` is `Update`, `finalize(&mut self) -> [u8; N]` is `Final` and returns the digest; `finalize` wipes the context in place where the C does `explicit_bzero(ctx)`, so it takes `&mut self`, not `self` (a by-value `self` would wipe a copy). `Default` is the wiped state, not a started hash (`sys/crypto/md5.rs`). Every hash or keyed context is not `Copy` (it stays `Clone` for a caller that forks a prefixed hash) and its `impl Drop` runs the `zeroize` that `finalize` runs too, field by field through `crate::crypto::wipe` and `explicit_bzero` (a `Drop` cannot `wipe(self)`: the assignment drops the old value and would recurse); its tests assert the missing `Copy` at compile time with `assert_not_copy!` (`sys/crypto/testutil.rs`, an ambiguous impl, since stable Rust has no negative bound). A parameter the C passes on every call but fixes per use becomes a const parameter of the type (SipHash's round counts: `SiphashCtx<C, D>`, `sys/crypto/siphash.rs`; BLAKE2s's digest length: `Blake2sState<N>`, whose range check is a `const` assertion) | The context cannot be updated before it is started or used across two algorithms, the digest is a value instead of an out parameter whose length must match, and a context cannot change its fixed parameters midway; no by-value pass or early drop leaves an unwiped copy of the state, which for SipHash, a keyed BLAKE2s and Idgen32 is key-derived (a move still can, as the row below says) |
| A run-time key kept in `Cell<Key>` (`Cell<SiphashKey>`: pf's SYN-cookie secrets, WireGuard's peer-table and rate-limit secrets, the inpcb hash keys, udf's node hash key) and copied out with `get()` onto the stack for every hash, never wiped; the key type `Copy` | the key type is not `Copy` and wipes itself in `Drop` (`SiphashKey`); a key that several CPUs read while one replaces it is its stored words in atomics behind a type of the crypto module (`AtomicSiphashKey`, `sys/crypto/siphash.rs`) that starts the hash from the words (`siphash24()`, `hash24(src)`, through `SiphashCtx::with_key_words`) and is replaced in place (`store`, `store_bytes`); a key behind a lock or written once at boot stays a `SiphashKey` used by reference | No key value is gathered on the stack per use, a replaced key is overwritten in its only storage, and the race the C has between a key being rewritten and a reader on another CPU (a wrong hash) stays a defined race instead of a data race on a `Cell`; no `unsafe`, and the owner's struct loses an `unsafe impl Sync` when the key was its last non-`Sync` part |
| A key schedule in a `Copy` struct (`[u32; 32]`, `AesCtx`, ...), wiped only when the framework `explicit_bzero`s the session | the schedule's own type, built by its constructor and `impl Drop` zeroing its words through `crate::crypto::wipe` (so it is not `Copy`); scratch secrets are still wiped where the C wipes them | The key cannot outlive its owner on any path (an early return, a replaced `Kschedule`, a freed session), without new `unsafe`; the stores go through `black_box`, so the optimizer keeps them. A move can leave a copy on the stack, as the C's by-value copies do |
| `Cell<*const T>` (`struct type *`) and `Cell<*const Cell<*const T>>` (`struct type **`) in a `queue.h`/`tree.h` entry or head, each read through its own `unsafe { p.as_ref() }` with "a linked element is valid" as its comment, `NULL` checked by hand or not at all | a typed intrusive link: a private type, `Link<P>` = `Cell<Option<NonNull<P>>>` (`None` is `NULL`), whose fields only the module's mutators write, from references, so a link carries the element's provenance; its invariant (a link of a head or of a linked element is `None` or names a live object) is stated once on the type and the dereference lives in one function (`Link::target`, `sys/sys/queue.rs`; `splay_follow`, `sys/sys/tree.rs`), whose `SAFETY:` is that invariant, kept by the `unsafe` mutators' contract (linked elements stay valid and in place); the algorithms are safe code on `&Elem`. The `_FOREACH_SAFE` walks share one cursor that holds the pending position as `NonNull`; tree.rs leaves a removed element holding no links, so readers stay safe on it. What the C turns into a `NULL` dereference is a `None` arm that panics (the panic row below) | One soundness argument instead of one per read (queue.rs: 49 `unsafe` blocks to 6), and the null case cannot be forgotten: an absent link is `None`, matched instead of compared; same size and auto traits as the raw pointer, so the structures that embed the entries do not change |
| `container_of` from a pointer taken from a field reference (`&elem.entry.next as *const _`, stored as the C's `tqh_last`/`tqe_prev`), stepping back with `unsafe` pointer arithmetic | the stored back pointer is made with the whole element's provenance (`NonNull::from(elem).with_addr(field.addr())`, `link_of`), the step back is safe `wrapping_byte_sub` by the adapter's offset plus the field's (`container_of`), and only the dereference of the result is `unsafe` (`sys/sys/queue.rs`) | A pointer derived from a field reference may not reach the rest of the element; with the element's provenance it may, and the arithmetic needs no `unsafe` |
| An `unsafe trait Adapter` whose contract (`OFFSET` is the offset of the field `entry` returns) each implementer vouches for with an `unsafe impl`, written by `queue_adapter!` at every invoking site | A safe trait (`sys/sys/queue.rs`) whose contract is kept by construction and checked by tools: only `queue_adapter!` (and `tree_adapter!`, through it) implements it, computing `OFFSET` with `offset_of!` of the very field `entry` projects; the macro checks at compile time that the field's type is exactly the entry type (`let _: *const $entry = addr_of!(elem.$field);`: a raw pointer never deref-coerces, so a `Box` or reference field is refused, a `compile_fail` doctest proves it); `cargo xtask lz check` refuses a hand-written impl, a rename of the trait and an impl whose trait is a macro variable. The core's `SAFETY:` arguments that rely on it cite this "adapter premise" | Under `#[forbid(unsafe_code)]` an `unsafe impl` expanded from a macro is refused in the invoking module (`docs/ZERO_UNSAFE.md`, section 3), so every module that declares a list or a tree could not be `forbid`. The one place where a CI check over the source, a tripwire rather than a proof, upholds a premise of the core's soundness; a reviewer still refuses any other way around it (decision 7) |
| A pointer stored as an integer and turned back (`p as usize`, `(cookie ^ v) as *const T`: `XSIMPLEQ_XOR`) | `p.expose_provenance()` to encode and `ptr::with_exposed_provenance(_mut)` to decode (`sys/sys/queue.rs`) | Rust's explicit API for the round trip: the decoded pointer is one the compiler allows to be dereferenced, and the intent shows |
| A C algorithm over raw links (`struct rb_entry *`) ported as `*const Entry` locals, an `unsafe fn e(p) -> &Entry` and an `unsafe` block per step; a generic root that any `rb_type` may walk; the mirrored left/right halves written twice | A typed handle, `RbNode<'a, T>` (`sys/kern/subr_tree.rs`): a `Copy` wrapper of the link, typed by the tree's `RbType`, made only from the element's own entry (address arithmetic by `map_addr`, which keeps the element's provenance) or from a link read out of a tree of the same type; its accessors (`left`, `parent`, `set_child`, `color`, ...) are safe, and the module's two dereferences (`RbNode::entry`, `rb_e2n`) carry the soundness argument. The root is `RbTree<T>`, typed by its `RbType`; the mirrored halves are one path over a `Side` | The algorithm becomes safe code with the C's control flow; a link of one tree cannot be read with another type's offset; a missing node the C would dereference as null is a `None` the code must handle (here, a panic naming the broken structure) |
| A broken precondition that the C turns into a fault or silent corruption (a `NULL` dereference in `TAILQ_REMOVE`, `SIMPLEQ_REMOVE_HEAD` of an empty queue; a null child in a rotation, a poison value followed, a tree element removed twice or never inserted, which empties the tree), mirrored in LZ by dereferencing the raw pointer | an `Option` match or a checked link whose failure calls a `#[cold]` module function that is `panic(9)` in the kernel and `std::panic!` under `cfg(test)` (`queue_panic`, `sys/sys/queue.rs`; `rb_panic`, `sys/kern/subr_tree.rs`), in every configuration, with a message naming the operation or the broken structure; `#[should_panic(expected = ...)]` tests cover each case | The fault stays a fault, with a message instead of a trap, deterministic, and never becomes a silent no-op; the host's `panic(9)` ends the test process (`boot` exits), so the test build unwinds and `#[should_panic]` can test each case |
| A global written once at boot and read afterwards (a function table, a console, an attachment), spelled `StaticCell<T>` whose every access is `unsafe` and names the boot phase that excludes a writer | `hal::once::OnceStatic<T>`: `set(v) -> Result<(), T>` succeeds once and hands a later value back, `get() -> Option<&T>` is `None` before the set; one atomic state byte (`EMPTY`, `BUSY`, `READY`) orders the one write before every read; each reader decides, as a type, what "before set" means (`sys/hal/once.rs`) | The phase the `StaticCell` caller promised is checked instead, and no caller writes `unsafe`; `StaticCell` stays in `libkern` for the legacy tree (`hal` depends on `libkern`) and its uses move with their subsystems |
| A direct call from new code into a subsystem that has not moved yet (`splraise`, `curcpu()`, `tsleep`, `km_alloc`, `malloc`, `pool_get`, `copyin`), which would make `hal` or `kernel` depend on `bsd` | a bridge: a trait declared beside its caller (`hal::intr::IntrLevel`, `hal::cpu::CpuId`, ...), one private `OnceStatic<&'static dyn Trait>` slot in `sys/hal/bridges.rs` with a `register_*` function `bsd`'s `main()` calls once, a crate-private reader that answers `None` before registration, and a row of `bridges.toml` (`trait`, `for`, `paid_by`); each primitive documents its behaviour without the bridge (no interrupts yet, one boot CPU, ...), never a panic in a hot path | The dependency arrows go down only (docs/ZERO_UNSAFE.md 0.1); what goes up is a registration, audited in one file and counted in one table that must be empty at N9; a bridge has no logic, so it moves without a behaviour change |
| `s = splraise(ipl); ...; splx(s)` (and `splnet()`, `splbio()`, ...), the restore written by hand on every path out | `hal::intr::splraise(ipl) -> SplGuard`, whose drop is `splx` of the level it replaced; not `Send` (`sys/hal/intr.rs`); the raw pair stays crate-private for the locks that keep the old level in the lock (`mtx_oldipl`) | No path can leave the level raised, and the guard cannot be dropped on another CPU |
| `struct mutex` and free functions (`mtx_enter(&m)` ... `mtx_leave(&m)`), the protected fields `Cell`s beside the lock, every access trusting the caller to hold it | `hal::mutex::Mutexed<T>`: the lock owns its data; `lock()` is `mtx_enter` (level raised, owner word swapped, spins counted) and returns a `MutexedGuard` through which alone the data is reached (`Deref`/`DerefMut`), its drop is `mtx_leave`; not `Send`; `try_lock()` is `mtx_enter_try`; the owner word is never 0, so exclusion rests on the compare-and-swap alone (`sys/hal/mutex.rs`) | The guard is the proof of the lock: an access without it does not compile, a path out cannot forget the leave, and the protected data needs no `Cell`; the legacy `Mutex` stays for its 129 files (decision 8) |
| `struct cpumem` handles to `ncpusfound` pool or `malloc` allocations reached by raw pointer (`cpumem_enter` -> `NonNull<u8>`, cast by each user); `counters_*` over `*mut u64` | `hal::percpu::PerCpu<T>`: `MAXCPUS` cache-line aligned slots of `T` by value, `get()` the running CPU's (`&T`), `iter()` the `ncpusfound` copies; a `const fn new()` for `T: PerCpuInit` (atomics), so a static needs no boot allocation; `Counters<N>` keeps the C's generation protocol under `MULTIPROCESSOR` and `read()` returns the sums (`sys/hal/percpu.rs`) | No allocation and no cast: the per-CPU discipline is `T`'s own interior mutability, and the type is `Sync` exactly when `T` is; the price is `MAXCPUS` slots, so an instance never lives on a kernel stack |
| `struct rwlock` with free functions (`rw_enter_write(&l)` ... `rw_exit_write(&l)`), the protected fields `Cell`s or raw pointers beside it, `rw_assert_wrlock` where the C asserts, and `rwsleep_nsec(ident, &l, ...)` re-entering the lock behind the caller's back | `hal::rwlock::Rwlocked<T>`: `write()`/`read()` (and `write_flags`/`read_flags` with `RW_NOSLEEP`/`RW_INTR`, `try_*`) return a `WriteGuard` (`&mut T`) or `ReadGuard` (`&T`) whose drop is the exit; `guard.sleep_nsec(ident, prio, wmesg, nsecs)` is `rwsleep` on `&mut self`, the lock held again on return whatever the sleep said; `guard.unlocked(f)` runs a copy that may fault with the lock released; `downgrade`/`try_upgrade` consume the guard; the C's waits, priorities, writer preference and wakeups are kept (`sys/hal/rwlock.rs`) | No reference into the data lives across a sleep or an unlock (the borrow checker sees the `&mut self`), the assertions are types, and a writer's exit compares the word it stored, so exclusion never rests on the `Sleep` bridge; the legacy `Rwlock` stays for its 72 files (decision 8) |
| `pool_get(pp, flags)` cast to the type and initialised by hand, handed out as `&'static T` (`pipe_pair_create`), `pool_put` wherever the owner decides | `hal::pool::TypedPool<T>`: one `pool(9)` per type (so `vmstat -m` lists it), `init(ipl, flags, wchan)`; `get_shared(flags, init) -> Option<PoolArc<T>>` writes the value before any handle exists; `PoolArc<T>` is an owned counted handle (`Clone` +1, `Deref<Target = T>`, the last drop drops the `T` and puts the item back); no `&'static T` and no raw form (`sys/hal/pool.rs`) | Decision 10: a reference borrows a handle, so a use after free or a double put cannot be written; the pool behind it is still the C's, through the `PoolBackend` bridge |
| `km_alloc(len, &kv_any, &kp_pageable, &kd_waitok)` kept as a `void *` and a size beside it, `km_free` with the same modes on every path, slices over it in `unsafe` blocks (`pipe_buffer`) | `hal::kmbuf::KmBuf`: owns the pages, `Deref`/`DerefMut<Target = [u8]>`, moves like a value (out of a lock while a copy that may fault runs, then back, decision 11), its drop is the `km_free` with the modes it was made with (`alloc_pageable`, `alloc_wired`) (`sys/hal/kmbuf.rs`) | The pointer, the size and the modes cannot disagree or leak, and the bytes are a slice; the pages are still `uvm_km`'s, through the `PageMemory` bridge until N3 |
| New code trusting the kernel's allocators silently (`km_alloc`, `pool_get`, `malloc` used as raw pointers at every caller) | a safe memory bridge (`PageMemory`, `PoolBackend`/`RawPool`, `Malloc`) returning a block and the size granted; the trust is the boot registration contract (registered once by the kernel's boot path with its own allocator, before any user; `sys/hal/bridges.rs`), named in the `// SAFETY:` of every `hal` site that makes a reference of a block, and every answer goes through `trust::check_block` (aligned, size covers the request, a write-and-read-back probe under `diagnostic`; a failure is `panic(9)` naming the bridge) (`sys/hal/trust.rs`) | Decision 30 (the user rejected `unsafe impl`s in `bsd`): `bsd` registers with no `unsafe`, `hal`'s API stays safe, and the trust is one documented boundary with runtime checks, not a compile-time proof, that goes with the bridges (N3, N9) |
| `p = malloc(sizeof(*p), M_KEVENT, M_WAITOK)` ... `free(p, M_KEVENT, sizeof(*p))`, the type and the size repeated at both ends, or a Rust `Box` (the global allocator's `M_TEMP, M_NOWAIT`) | `hal::malloc::MBox<T>`: `MBox::new(ty, flags, value) -> Option<MBox<T>>` with the C's malloc type and `M_WAITOK`/`M_NOWAIT`/`M_CANFAIL` (`None` only where the C's `malloc` returns `NULL`), `Deref`/`DerefMut`, the drop drops the `T` and frees with the same type and size; a type `malloc` cannot align, or a zero-sized one, refused at compile time (`sys/hal/malloc.rs`) | Decision 19: `vmstat -m` counts the block in the C's row and `M_WAITOK` sleeps where the C sleeps; the two ends cannot disagree |
| `copyin(uaddr, &obj, sizeof(obj))` with a `usize` address, over an `unsafe trait AbiPod` vouched for by an `unsafe impl` per type (about 200, `sys/machine/copy.rs`) | `hal::user::UserPtr<T>`: a user address typed by what it points at; `copyin() -> Result<T, Errno>`, `copyout(&T)`, the `_slice` forms for arrays, `copyinstr`/`copyoutstr` on `UserPtr<u8>`; `AbiPod` is a safe trait written only by `abi_pod!(Type { field: Type, ... })`, which checks at compile time each field's exact type, that each is `AbiPod`, and that the fields in order tile the type with no padding and none left out (`sys/hal/user.rs`) | Decision 17: the byte view's one `unsafe` lives in hal and rests on a compiler-checked premise (and `lz check` refusing other impls, as for `Adapter`), so the kernel and the ABI module copy structures with no `unsafe`; the size is the type's |
| An LZ module reached at its old `crate::` path (`crate::arch::amd64::include::frame`, `crate::machine::param`) | Moved into `hal` (`sys/hal/arch/`, `sys/hal/machine/`, `sys/hal/sys/`) as an `inherited` module, code untouched; the old parent `mod.rs` keeps the name with `pub use hal::...;` | The hardware lives in the one crate with `unsafe`, and the generic modules and the remaining arch files keep their paths; a re-export is a rename-free move. An inherent `impl` on a moved type can no longer be written in `bsd` (orphan rule): none existed. |

## Candidates (not settled; each becomes a row when first used)

- `Cell<T>` on every field the C mutates behind a shared pointer -> the fields owned by the
  lock's guard (`Mutex<State>`), or `&mut` where the call graph proves exclusivity. Why: the
  lock proves the aliasing the `Cell` only promises.
- C-shaped out parameters (`&mut T` filled on success, an `Errno` returned) -> `Result<T, Errno>`
  returning the value. Why: a value that exists only on success is a `Result`.
- `*mut u8` + length at an internal API -> `&[u8]` / `&mut [u8]` all the way to the copyin/
  copyout edge. Why: bounds are the slice's.
- `unported!("x")` for an inherited gap -> unchanged until the redesign closes it; then gone
  with its `## Deviations` line. Why: gaps stay visible, never widened.
- `unsafe impl Send/Sync` as a marker on a C-shaped struct -> the struct made of `Send`/`Sync`
  parts, the marker gone. Why: the compiler proves it.
- A `#[repr(C)]` struct shared with userland -> unchanged, ever. Why: it is the ABI.
- `StaticCell<T>` (626 uses at the M16 pin): a global in an `UnsafeCell` whose
  `get_mut(&self) -> &mut T` leaves the aliasing proof to every caller -> the state owned by
  the lock that guards it (a `Mutex<State>` in the static), per-CPU state behind its
  interrupt-level guard, or an init-once cell for tables written only at boot. Not solved yet.
  The constraint: `libkern::StaticCell`'s API is frozen by the timing rule (N1), so each use
  moves with the subsystem that owns it; meanwhile a redesigned module adds no new use, and a
  moved `unsafe` that reappears as a `get_mut` call does not count as a reduction. Why: the
  `unsafe` budget counts sites, and `get_mut` hides one at every caller.
- A `&'static T` made from a raw pointer (`kern_sig.rs` `parent() -> &'static Process`;
  `uvm_map.rs` `uvm_mapent_free(&'static VmMapEntry)`, which hands the entry back to its
  pool) -> a reference whose lifetime is a borrow of its owner (the lock guard, the parent's
  handle), or a typed handle (a refcount, an index) where the object outlives every borrow.
  Not solved yet. The constraint: a safe function that takes a `&'static` and frees the
  object makes a use after free expressible in safe code, so no redesigned module creates a
  new one, and the subsystem that owns each existing one (N3 uvm, N4 proc) removes it. Why:
  `'static` is a promise the pool breaks.
