EmiBSD

An operating system in Rust, grown from the faithful port of the OpenBSD kernel.

Ferffy — half Ferris (Rust's crab), half Puffy (OpenBSD's pufferfish).

  • License: ISC
  • Rust: stable
  • Targets: amd64 · arm64
  • Runs in: QEMU
View on GitHub Build it
Not for production. EmiBSD is an experiment. It runs only in QEMU, and its crypto, network and storage code is unaudited. Do not use it to protect real data or real networks.

What is this

EmiBSD is derived from EmiBSD.LZ, the file-by-file port of the OpenBSD kernel to Rust. LZ ports OpenBSD; EmiBSD redesigns what LZ ported.

  • OpenBSD's behaviour is the specification. The system-call ABI and everything userland sees never change: OpenBSD's own userland runs unmodified.
  • The inside changes, subsystem by subsystem. The goal is zero unsafe in the kernel: sys/kernel/ and sys/abi/ are #![forbid(unsafe_code)] crates; sys/hal/ is the only crate with unsafe, every site proved.
  • A standalone #![no_std] kernel for amd64 and arm64, booted by its own boot(8)/efiboot or by Limine, run in QEMU.

Quick start

git clone https://github.com/enavarre-cl/EmiBSD
cd EmiBSD
just build      # arm64 kernel (amd64 waits for N10)
just run-arm64  # boots it in QEMU, serial on stdio

Toolchain and QEMU setup, per platform, in SETUP.
