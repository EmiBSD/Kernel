# redesigner: lessons across runs

One line per lesson, appended at the end; task state goes in HANDOFF.md
(`.claude/rules/subagents.md`, "Memory"). Committed with the tree.
- The smoke ESP image (`IMAGE_SECTORS`, 256 MiB) holds the debug kernel and the ramdisk; inlining can grow `.debug_info` by MBs while `.text` shrinks, and `--expect-ramdisk` smokes fail "No space left on device": compare `llvm-objdump -h` of both `bsd` first.
- Worktree sandbox, git: plain single commands from the worktree root (`git show`, `git add <path>`), never `git -C`, never chained after another git call, never with variables or `$(..)`; read LZ at the pin with `git show 3c62ede68802:sys/<path>`; stage many paths with `git diff --name-only > <scratch>/paths.txt` and `git add --pathspec-from-file=<scratch>/paths.txt`.
- Worktree sandbox, shell: refused are awk programs, `$((..))`, `[ .. ]` on computed values, loops, `PATH=..:$PATH cmd` prefixes, `sed -i` with multi-line `c\`, `cat >> f <<EOF`, and heredocs whose text holds "git" or shell-looking words; what passes: `just <recipe>` as is, `/opt/homebrew/opt/rustup/bin/cargo` by absolute path, `python3 - <file> <<'EOF'` scripts, and scripts written with the Write tool into the scratchpad and run by path (watchers too).
- clippy `declare_interior_mutable_const` fires on a named `const` of a type with `Cell` links in tests; use an inline `const { .. }` block.
- `kassert!` without `diagnostic` still builds a closure per expansion; in generic hot helpers gate it with `#[cfg(feature = "diagnostic")]` and call `crate::kassert!` by path.
- A diagnostic bsd does not compile (ucom.rs, `usbd_errstr` not imported under cfg(diagnostic)): patch it locally for diagnostic tests, `git checkout` it before committing; an inherited file holding `unsafe` outside unsafe-core.toml cannot take even a one-line fix (redesigned must be forbid, adapted needs a cause), so such LZ bugs are the user's call (ucom.rs: N7).
- Clippy as `just clippy` runs it (lib only, host and `--target ... --features qemu`); `-p bsd --all-targets` drags in hundreds of unrelated test lints. Since decision 40 `multiprocessor` is a default of bsd only (hal and kernel have no such option) and lib.rs refuses a build without it: say `--features qemu`, never `qemu,multiprocessor`.
- Intrusive links: derive the entry pointer with `NonNull::from(elem).cast::<u8>().map_addr(|a| a.saturating_add(OFFSET))`, never from `&elem.field`, so container_of stays sound (docs/IDIOMS.md typed-handle row).
- clippy::type_complexity fires on `PhantomData<(&'a X, fn() -> T)>`; split it into two PhantomData fields.
- Safe readers over intrusive links are sound only if unlink clears the element's links and a poison value is flagged, never followed; tree(3) defines element ops only for linked elements, so clearing is no deviation.
- `crate::crypto::wipe(x)` is `*x = T::default()`, which drops the old value: a `Drop` calling `wipe(self)` recurses; wipe field by field in a `zeroize` (`explicit_bzero` arrays over 32) called by `Drop` and `finalize`.
- Dropping `Copy` breaks `Cell::get` and `StaticCell::read` at call sites: use `take`/`clone`/`set` on the Cell, `get().clone()` on the StaticCell. A stable "not Copy" check: `crate::crypto::testutil::assert_not_copy!` (E0283).
- `sys/lib/libkern/lib.rs` is a crate root AND an inherited `[[module]]`; `lz check` drops `#[forbid(unsafe_code)]` lines on `mod x;` declarations from the comparison, so the ratchet keeps it inherited.
- A file with no `unsafe` token still fails under forbid when it invokes a macro whose body has one (28 such macro_rules: byte_view!, scsi_wire!, usb_wire!, ...); lex macro bodies and grep invocations before trusting a sweep.
- Filtered `cargo test -p bsd --lib -- <names>` runs mislead (wg_ioctl_dispatch "no idleproc set on CPU0", cookie_mac_test* with uptime 0 fail at the baseline too): confirm a failure with the full `just test`.
- Under forbid, pf tests keep IPv4 addresses in the descriptor's own header copy (`PfLoc::Hdr(..)`) instead of `unsafe { PfLoc::local(ptr) }`.
- A non-Copy key in a `Cell` has no safe by-reference read and `take()`/`set()` exposes the zero key to other CPUs: a shared run-time key is `AtomicSiphashKey` (IDIOMS row); one in a StaticCell is read with `get()`.
- `[[module.fn]]` rows: a row lives only under a module whose `lz` list names its LZ file, and adapted modules carry none (an item leaving an adapted module means the redesigned target lists that LZ file with its licence, `//! Upstream:` and `//! LZ:` lines); bare `native` names resolve only in the row's module, others need `sys/<path>.rs::name`.
- Before promising "module X becomes forbid", list every `unsafe` in X: `unsafe impl AbiPod` on repr(C) structs (~200) and raw accessor derefs block it until a core mechanism exists.
- Taking a value out of an `OnceCell` through `&T` at proven exclusivity: `(*ptr::from_ref(&x.cell).cast_mut()).take()` (all UnsafeCell); never cast the whole struct to `&mut`.
- The scratchpad replacer (`repl.py <file> <spec>`): OLD/-----/NEW blocks split on `\n=====\n`, exact match once unless `@all`, `@END` inserts before the last `/* </CODE> */`, `@TESTEND` before the tests module's closing brace; a failed block writes nothing.
- Replacer pitfalls: the spec's final newline joins the last block's NEW (strip it; a stray blank line after a doc comment is clippy's empty_line_after_doc_comments, in a Markdown table it splits the table; grep the diff for `^+$`); `@all` matches substrings (an 8-space pattern also hits the 12-space copy).
- lineage's exclusion of `sys/stand/` covers only the kernel's boot glue (`mod.rs`, `bootarg.rs`, `limine.rs`): `sys/stand/boot/*.rs` and efiboot files are modules and turn `adapted` when touched.
- `hal-check` wants `// SAFETY:` on the line right above the one holding `unsafe`: bind the pointer first, then `let x = unsafe { .. };`.
- `abi-check` scans every `.rs` under `sys/abi/`, build scripts too: a `build.rs` there may not branch on a value.
- In a forbid crate `#[unsafe(no_mangle)]`, `export_name` and `link_section` are refused; a separately linked binary's entry is a `#[used]` static matched by a linker-script glob (`KEEP(*(.data.rel.ro.*NAME*))`) with `ENTRY(sym)`.
- A `no_std` bin linking `alloc` needs a `#[global_allocator]`; keep the crates a stateless module links (hal, kernel) free of `extern crate alloc`, or give the module an allocator over its vtable.
- Without a build (decision 23) `cargo fmt --all` is the only parser run (it caught `gen`, reserved in edition 2024): run it after every new file. `cargo fmt -p hal` also parses the cfg'd-out arch backends on the Mac (syntax only, no types).
- The hook's `cargo fmt --check` resolves every `mod` line, so a `git mv` of a module breaks the commit unless the old `mod` resolves; `#[path]` is forbidden even transiently (the user, 2026-10-16): git mv + re-export shim + mod fix in one commit.
- `#[cfg(..)] { value }` as a tail expression is unstable: write `if cfg!(feature = "..") { a } else { b }`.
- hal reaches panic(9) without naming bsd: `core::panic!` goes to the image's `#[panic_handler]` (bsd calls panic(9)) and unwinds on the host for `#[should_panic]`.
- Moving a legacy module into hal moves its `pub unsafe fn`s, which 0.2 forbids there (the lists and trees had 52 and moved back): `grep -c "pub unsafe fn"` first; hal pieces are written new with a safe API.
- `abi_pod!`-style tiling checks (`offset_of!` + sizes) miss unions and omitted zero-sized fields; an exhaustive `let $T { $($f),+ } = *v;` in a never-called closure refuses both.
- A guard that saves the old spl must record whether it raised anything: restoring IPL_NONE for a guard taken before the IntrLevel bridge was registered lowers the real level.
- OpenBSD opens BOTH pipe files `FREAD | FWRITE` (sys_pipe.c dopipe): which pipe a file holds cannot come from `f_flag`; carry it with the handle.
- `klist_assert_locked` with `kl_ops == None` asserts KERNEL_LOCK under diagnostic + MP: an MPSAFE object cannot use an ops-less klist with the `_locked` forms.
- `unsafe-report` counts `cfg(any(test, feature = "x"))` code as kernel code: never expose hal's `testutil` under a feature; a dependent crate's tests register safe doubles of hal's bridges themselves (sys/kernel/testutil.rs).
- A kqueue filter runs under its object's lock but is called through `knote_locked`, where no `Rwlocked` guard can be passed: what filters read sits outside the lock-owning state, as atomics stored under the guard (IDIOMS row).
- A `Native` syscall entry must still run bsd's prologue (mi_syscall: refreshcreds, pin_check, pledge_syscall, the kernel-lock rule) on its own sysent row with the syscall number, or the module path silently drops pledge and pinsyscalls.
- bsd's `Klist`/`SigioRef` (anything with `SlistHead`/raw-pointer Cells) are Sync but not Send, so they cannot sit in a `PoolArc` value; the glue holds a leaked, recycled `&'static` (pipe_glue's PipeKlists, IDIOMS row).
- `cargo xtask gen-syscalls` also writes a stale `sys/sys/syscall.rs` (the header moved to hal): delete it after running.
- Unsafe ratchet: `unsafe-report --write` sets every row to its count, so one new `unsafe` (core rows too) fails `--check`: read the row before promising `Unsafe: x n -> n+1`, design for zero first; a subagent's commit raising a ratchet (hal_ceiling) is refused by the permission classifier: stop, leave the message in the scratchpad, the user commits it.
- amd64's kernel_map never executes (pg_nx on every directory entry); executable kernel pages live only under the KERNBASE slot. arm64's executes unless PXN is set on its tables.
- Under Limine a kprintf inside pmap_bootstrap did not reach the transcript (boot(8)'s did): prove early-boot code by an effect printed later.
- `cargo xtask lz trace` takes `<lz path>:<item>` with ONE colon (`::` silently says "not found"), lowercases its answer line and does not see fns in `extern` blocks; neither is a missing row.
- lineage treats every `mod.rs` and all of `sys/hal/arch/host/`, `sys/hal/machine/` as structural: a hal API that needs a `[[module]]` record is `x.rs`, not `x/mod.rs`.
- `bridges.toml` `paid_by` accepts `N2`..`N9` only: a slice (N3.3) goes in the row's comment.
- A hal API whose backends land later: gate `pub mod x` and its `bridge!` slots (`#[cfg]` works on the macro call) to targets with a backend so both machines build at every commit; `bridge!` takes an optional `#[attr]` for `allow(dead_code)`.
- `lz check` (the hook) walks every .rs on disk, untracked too (it refuses an untracked .rs under sys/): to commit in the middle of work, save `git diff`, move new files out, `git checkout`, commit, `git apply --3way` and move them back.
- `#[forbid(unsafe_code)]` also refuses an `unsafe fn` declared in the module: a wrapper needing a caller promise goes in the non-forbid caller.
- The arm64 kernel target is `aarch64-unknown-none-softfloat`; `--target aarch64-unknown-none` fails "can't find crate for core" (not installed), no code error.
- arm64's `ap_bits_user[PROT_EXEC]` is execute-only (AP 0b10): write PTE asserts from the C's table, not intuition.
- `PoolBox`/`SharedBox` are two words (item + pool): a one-word page slot (arm64's vp3 `vp[]`) needs `SharedBox::into_raw`/`from_raw`. `Option<PoolArc<T>>` (and a `Cell` of it) is one word: it replaces a raw pointer field without moving a `vmstat -m` size (assert with `const _`).
- `in` is a keyword: an `asm!` operand named `in = out(reg) _` does not parse.
- `[[dropped]]` is refused for an LZ file still in any module's lz list: an LZ file absorbed by hal modules that list it needs only the rows for items no hal item covers by name.
- lz check resolves trait-impl methods as `Type::method` in any file (mod.rs and machine adapters can be targets), but a trait method declaration is not a target: name the implementing type's method by path (`sys/uvm/uvm_fault.rs::VmMap::note_minflt`).
- When the direct map's base moves into `hal::pmap::bootstrap`, what used LZ's early static before it (amd64 consinit: efifb, the VGA hole) breaks: bootstrap before consinit.
- A device softc is zero-initialised by autoconf: a non-pointer handle (`Option<PmapRef>`) lives in a module `OnceStatic`, the softc keeps the raw pointer for identity.
- bsd's host tests run on kernel::testutil's doubles for every hal bridge (installed once per process by arch/host's lazy pmap bootstrap), never bsd's subr_pool; a kernel bridge's doubles get their own installer (km_install); where legacy code feeds a kernel assertion (KERNEL_LOCK held) register bsd's real bridge first; a bsd static over a kernel provider needs a `#[cfg(test)]` const (PIPE_PAGES).
- arm64 hal: `Backend::virtual_space()` sets PMAP_VIRTUAL_SPACE_CALLED (vp tables stop being stolen): bootstrap code uses VM_MIN/MAX_KERNEL_ADDRESS or `stolen_bounds()`.
- arm64 layout: the image (0xffffffff80000000) is L1 slot 510, kernel_map/vmmap L1 slots 0..15 of L0 slot 511, the direct map L0 slot 0; grep hal's inherited include/pte.rs before adding a C constant (Lx_PT_PXN was there).
- `lz check` refuses a `redesigned` bsd module outside unsafe-core.toml whose `mod` line is not forbid: a header split into kernel that keeps `unsafe` behind (uvm_extern's Vmspace) is `adapted` by the kernel modules; a 0-unsafe adapter gets forbid and is `redesigned`.
- clippy `too_many_arguments` counts `&self` on a trait method declaration (7 max); one `#[allow(.., reason)]` there covers the impls.
- `core::arch::x86_64::__cpuid` is safe on 1.98.1: hal reads CPUID with no new `unsafe`; bsd's `#[allow(unused_unsafe)]` around `__cpuid_count` is a leftover.
- A redesigned module whose `lz` list mixes a no-licence source (cpuswitch.S) with a licensed one drops `license = "none"` (AuthorOnly refuses the second block); say it in `notes`.
- hal::module::load's `LOADING` once-guard is process-wide: test later steps through `place_and_map`, never a second `load_with`.
- arm64 at pmap_bootstrap: TTBR0 holds only bsd's 1 GiB device map (PXN) on both loaders, so no executable identity map exists; a TTBR1 switch that changes the block size of live global entries needs break-before-make (the C and Linux run it at its physical address).
- arm64: stable rustc emits no BTI landing pads, so kernel text must not carry ATTR_GP on FEAT_BTI hardware (QEMU's cortex-a72 ignores it: no smoke catches it).
- A global_asm! routine's address with one unsafe site: its words as a `safe static` with #[link_name] in an `unsafe extern` block, then `ptr::addr_of!`.
- Limine 12.9.3 writes TCR_EL1 = T0SZ/T1SZ | 0xb5003500 | IPS<<32 | DS (no HPD, AS, A1): `llvm-objdump -d` of BOOTAA64.EFI answers what Limine leaves in a register.
- To host-test hal arm64 code over the inherited include/pte.rs, sys/hal/arch/mod.rs aliases crate::arch::arm64::include to host's header copies under cfg(all(test, not(target_os = "none"))).
- Before kmeminit (pmap_init and uvm_init_early sit before it) the Rust global allocator is unavailable ("memory allocation of N bytes failed" right after the copyright): every TypedPool/BoxPool made then takes one of hal_bridges.rs's NSTATIC_POOLS static `struct pool`s, past them boot panics "more than NSTATIC_POOLS"; count the pools a change or a flip makes there (uao_init, rw_obj_init).
- A pmap window computed from loader input is checked non-empty at bootstrap (amd64's kernel window under Limine depends on QEMU's map: HHDM to ~1 TiB puts it in slot 258); test the arithmetic with layout.rs's table, the 1 TiB case included.
- MP host tests share CPU 0's per-CPU page magazines across setup_real_memory (uvm_page_test_reset resets them; a new per-CPU cache of kernel memory needs the same), and frees land there: count `uvmexp.free + percpucaches`; kernel tests over the real page system hold `testutil::MEMORY`.
- `hal::pmap::bootstrap` runs once per test process: a crate's test modules share one bootstrap (`testutil::pmap_boot`), with a provider whose `page_init_done` is false while tests steal memory.
- hal `List`/`Tree` elements stay `linked` until removed: drain a stack `Pglist` (`pop_head`) before it leaves scope, empty an object's tree by removal; there is no TAILQ_INIT/RBT_INIT over a non-empty head.
- lz check accepts a `pub use` re-export in an adapted module as an LZ item that moved, until a kernel module lists the same LZ file: then the re-export is no item and needs a `moved` row (uvm_pagecmp).
- Edit TOML rows by exact text, never a regex like `[^\[]*` (it stops at `for = [`), and run `lz check` (it parses bridges.toml) after; a `[[module]]` inserted after another's `notes =` line re-parents its `[[module.fn]]` rows: insert before the next header.
- A refused command (a `sed` of `reference/emibsd-lz/...` through the symlink) is never routed around (subagents.md): report it and ask for the excerpt.
- A kernel macro and a fn of the same name in one module clash at `pub(crate) use` (E0255): name the helper differently (`report_unported`).
- A "printed once" stub both bsd and kernel call keeps LZ's once-per-boot output only with ONE site: in the kernel, bsd's function delegating (bsd's module turns adapted).
- `amap_lookup` panics on an entry without an amap: unwire/wire paths test `aref.amap().is_some()` first (shared file and aobj mappings have none).
- Measuring a baseline inside the worktree: commit, `git checkout -q <base>` alone, run, `git checkout -q <branch>`, editing nothing between.
- hal's `pmap` module is forbid on its `mod` line: a pmap piece with `unsafe` goes in a file of its own (`sys/hal/mapped.rs`, an `[[extra]]`) with an inherent `impl KernelMapper` there.
- `PoolArc::get_mut` (count 1) is unsound beside `PoolArc::from_value` (rebuilds a handle at any count): recorded pools (`init_recorded`, the pmaps) answer `None`, and `from_value` refuses other pools.
- A sealed hal trait (`Witness`): an inline `mod sealed { pub trait Sealed {} }` in CODE passes lz check; an unsealed witness trait lets a fake impl forge a lock. A frozen signature naming a hal type another slice adds can be written `w: &impl Witness`.
- A lock-keyed cell a `const`/`static` builds (`Guarded::new_static`) cannot store the address as `usize` (not const): `enum { Static(&'static RawRwlock), Addr(usize) }`, auto Send + Sync.
- Kernel test doubles: hal's malloc double serves `malloc(0)` (`mallocarray(0, ..)`, tmpfs's `uao_create(0)`); `pages_install` needs 256 pages (64 left `uvm_pagealloc` at None); the pool double never fails but `testutil::fail_pool(wchan, n)`; `uvm_page_unbusy` asserts `!PG_FAKE` under diagnostic (clear it in the test).
- A safe byte view over a frame (`MappedBytes`) needs a per-frame claim bit only hal sets (`PG_HAL_VIEW`) and a capability (`KernelMapper`); "not a frame backing kernel memory" stays the token holder's contract until typed pages: say so, never "as KmBuf's".
- Owned chain cursor: `loop { match cur { Some(c) if c.k != k => cur = &mut c.next, _ => break } }` then using `cur` is refused (NLL case 3): find the position with a shared walk, then step `at` times (amap.rs `chain_position`/`chain_at`).
- Before planning a flip of an owner to witness locking, grep its callers for locks taken in one function and released in another (uvm_fault: ~15 unlock paths, rw_status checks): those need their protocol redesigned, not call-site edits.
- A setter taking `&WriteWitness` cannot run while a `Guarded` cell of that lock is open through `get_mut(&mut w)`: counters under a foreign lock are relaxed atomics whose setters `kassert!` the lock.
- `SharedRwlock` is 16 bytes (two pointer arms, no niche): a pool item cloning one grows by 16; vmstat -m item sizes are userland-visible: check `size_of` and compare smoke-diag's pool table with a recent log before a flip, listing every row that moves.
- A function that makes a value and returns a witness borrowing it takes a `&'v mut Option<T>` slot: `let v: &'v T = slot.insert(t);` returns `(&'v T, Witness<'v>)`.
- `uvm_swapisfull()` is true with no swap (0 >= 0): out-of-RAM faults return ENOMEM, not ERESTART; a retry test raises `UVMEXP.swpages`. `uvmfault_anonget` counts rusage on every retry (the C's `goto retry`).
- Machine lock: release only what you took; take-run-release in a script that releases only after its own `mkdir` succeeded (N3.4c once removed another agent's lock).
- Host pager tests: `km_alloc` with `KP_NONE`/pageable is `None` on the host (`PMAP_NOMMU`): seed `PSEGS[0..2].start` and keep windows to one page; the host pmap double has no pv chain and never fails `pmap_enter` (and grows no logic): put such decisions in a `PageMd` helper the host tests and say what stays untested.
- A kernel test acting "inside VOP_READ" uses `testutil::MemVnode::during_read(f)`; one acting while everything is unlocked uses fault.rs's swap-get stand-in or a scripted `FaultObject`.
- A kernel trait method implemented by bsd over functions taking `&'static Vnode` can declare `fn m(&'static self)` (object-safe for `&'static dyn`).
- A `Cell<Option<Handle>>` read by take/clone/set is a write: under a read lock (two faults on one entry) it needs its own guard (an AtomicBool spun on, in padding); a 4-thread host test catches it, smoke-mp did.
- An owning container's `remove(&mut self, e: &T)` cannot take an `e` borrowed from it (E0502): give find-and-remove by key (`OwnedTree::take_by`) and validate elements by a container identity in their entry.
- `Guarded::get_mut(&mut w)` borrows the witness for the reference's life: two `&mut` cells of one lock need the witness split into parts (`Divisible::split`); parts borrow the witness, so return a value holding them (`MapSplit`) with `parts(&mut self)` (IDIOMS row). Check a brief's guard signatures against this before freezing an API.
- Test helpers calling `init_shared()` (any `TypedPool::init`) from parallel tests race (EBUSY, then no pool, ~1 in 20): wrap the init in a `std::sync::Once`.
- `try_read` by the holder of the write witness panics "enter read deadlock" (the C's check): test "held elsewhere" from another thread (`thread::scope`).
- bsd's `uiomove` over one `UIO_SYSSPACE` iovec is a safe path to `kcopy` (pcb_onfault); making `kcopy` safe would launder legacy blocks and give bsd a safe arbitrary-address write.
- A removal that calls adapter code (augment, entry) on the element must re-read the secondary count after the last such call, before rebuilding the box (the S0 UAF).
- Before writing a kernel module over a frozen hal API, grep the C for every primitive it calls (arc4random, sched_pause, ratecheck, `(struct outer *)field` casts) and check each is kernel-reachable: `bridge!` readers are `pub(crate)` to hal.
- Over an owned intrusive tree, name elements by unique key across inserts, removals and clips (clip_start returns the clip address); a loop that clips its own cursor updates `first` when `key == first`.
- A trait method reading lock-guarded fields without a witness parameter cannot be implemented over `Guarded`: move such reads to the guard trait (`g.aref(e)`).
- A trial `git merge --no-commit --no-ff <branch>` + cargo check, then `git restore` + `git merge --abort`, measures a parallel branch's API mismatches exactly.
- `std::panic::catch_unwind(|| f(&x))` stops compiling once `x` gains cells: wrap in `AssertUnwindSafe`.
- Coding against an API another agent writes in parallel: keep its assumed signatures as a never-committed stub file and a script that swaps it out before each commit and back after.
- clippy doc_lazy_continuation: a `//!` continuation line starting with `+`, `-` or `*` reads as a list item; reword.
- Shared kernel test maps go below the host's VM_MIN_KERNEL_ADDRESS: the map tests store UVM_MAXKADDR downwards, which desyncs a best-fit map above it ("uaddr_bestfit_remove: entry was not in tree").
- A mechanical `use` rewrite that splits one `use` into several drops the `#[cfg]` on all but the first: list HEAD's attributed uses and fix those by hand.
- Derived state cached inside `MapState` (Owners, ~180 B) grows `Vmspace` past `the_pool_items_stay_near_the_cs`'s 512 B (vmsppl item size, vmstat -m): compute once per operation and lend `&T` down instead (as fast, no size change).
- A `&'s VmMapEntry` returned from a `&'s mut MapState` keeps the whole state borrowed; inside a loop that reborrows the state NLL refuses it (universal region): return a `Copy` summary, or reborrow with `OwnedTree::insert_get` + destructuring `let MapState { addr, uaddr_exe, .. } = st` for split borrows.
- The vm host bench is noisy: some fault rows are bimodal run to run (15-20 %) and dev primitives move +-10 % when unchanged code is re-placed by a rebuild; take two runs per profile (lowest median) and prove "same work" with a dump of the map's entries before and after.
- Worktree sandbox: python heredocs whose text holds test/word fragments ("sane", "split", ...) can be refused as "too complex"; write the script with the Write tool and run it by path.
- The guard hook allows the reference symlinks only as `ln -s <main>/reference/<tree> reference/<tree>` (a relative link name, run from the worktree root, one command each); an absolute link path is refused as a write under reference/.
- LZ frees pool items and softcs without dropping them (`proc_free` is a raw `pool_put`; tcpcb, syn cache, sessions likewise): an owning handle (`PoolArc`, `MBox`) inside a legacy struct leaks there; grep the struct's free path before giving it an owning field.
- A legacy header type whose fields other bsd code uses directly (`struct task`: if_.rs's hooks and ifq.rs's serializer link it by `t_entry` and run it by `t_func`/`t_arg`/`t_flags`) cannot be replaced by the kernel's type: keep it and embed the kernel's type as a field.
- `lz check` counts an LZ file's `const _: () = { .. };` as an item named `_`: deleting the file needs a `[[module.fn]]` row `lz = "<path>::_"` (or a `const _` in the native module).
- Decision 43's "before": a scratch test appended to the inherited LZ module's tests, run with `cargo test -p bsd --lib <name> -- --nocapture` (dev ~2 min) and `--release` (LTO, ~5-7 min); `git checkout` the file before any commit (the hook refuses an inherited file that differs).
- kernel::testutil's doubles are slower than sys/arch/host's (an IPL_HIGH lock pair 9.6/6.9 ns dev/release vs 4.3; wakeup_one 15.3/9.2 vs 4.6): bench a `prim.*` row on both sides so a slowdown is attributed to the doubles or to the design, and profile with the bench's `--profile NAME SECS` mode and macOS `sample <pid>`.
- A task's `pending` kept as its pinned entry's link word (one atomic, cleared by the unlink itself) avoids touching an element after unlinking it, which a separate flag cleared after the unlink would need.
- Before embedding a kernel type by value in a legacy struct, check it is valid all zero: autoconf softcs (and other M_ZERO memory) are cast under `unsafe impl Softc` proofs that cite their members' all-zero validity, and a hal `Guarded::new_static*` key holds a `&'static` (not zero-valid): kernel::timeout::Timeout could not go into sys/sys/timeout.rs (N4.1 path (a'), an address-keyed node).
- `hal::tree::Tree::find_by`/`OwnedTree::find_by`/`take_by` take `key.cmp(&node.field)` (key first, the C's cmp(key, n)); the reverse finds the root only.
- kernel::testutil's pool double makes a fresh zeroed page per item and never reuses one: a bench op taking pool items must register a recycling backend first (benches/vm.rs's, copied into benches/timeout.rs), or it times the host's page faults (extent 1,540 vs 123 ns).
- Decision 23 leaves tests unrun, but a filtered host run of the new module's own tests is minutes and caught two bugs compile-only would have committed (a reversed tree search, a test asserting a C quirk away): run them before the commit.
- A `git rm --cached` or `git rm` staged earlier rides along in the next `git commit`: `git restore --staged <path>` before committing another piece alone; the hook's lz check reads the disk, so a partial commit needs the whole working tree consistent.
- hal::owned's OwnedTree::next(e) re-checks the entry's identity per call: walk with one `iter()` (peekable, `next_if`) where the C walks a list; it cut extent's best-fit op 144 -> 123 ns.
- Over `reference/`, read with `sed -n A,Bp <file>` or `grep -n -A N <file>`: a pattern-range sed script (`sed -n '/re/,/re/p;...'`) was refused by the permission system (N4.1 review fixes); find the line numbers with `grep -n` first.
- A token-level hal-check rule over a sealed trait needs a seal name no other trait uses (`pinlist::sealed::PinSealed`, not `Sealed`: hal::rwlock's Witness has its own `sealed::Sealed`); refusing every naming of the seal outside its file also catches `use .. as` renames.
- lz check: an `adapted` module may list only the LZ file of its own path, and a `redesigned` bsd module outside unsafe-core.toml must be forbid: a legacy adapter that keeps an `unsafe impl Sync` (sys/sys/task.rs) can be neither redesigned nor list a second LZ file; that is the user's call (unsafe-core.toml).
- A legacy holder that hands out `&'static T` from a `Cell` (softc fields read by `get()` beside a destroyer) cannot hold a freeable counted handle safely (no by-reference read of a `Cell<Option<Arc>>`, take/clone/set exposes None, OnceStatic never empties): only holders with their own unsafe deref (wg's AtomicPtr) or a local handle can free; check before promising a free.
- clippy `drop_non_drop` fires on `drop(view)` of a struct holding only `&mut` borrows: let NLL end the borrow at its last use instead.
